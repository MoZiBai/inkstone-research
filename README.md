# 砚台（Inkstone）

砚台是一款面向深度阅读的 Windows 桌面应用。你可以在同一个项目中阅读 PDF、标记原文、记录想法，并把摘录整理成卡片和写作提纲。资料默认保存在本机，核心功能不需要账号、云服务或生成式 AI。

## 下载与安装

在 [Releases 页面](https://github.com/MoZiBai/inkstone-research/releases) 下载最新的 Windows 安装程序（文件名以 `_x64-setup.exe` 结尾），运行后按提示安装。当前提供 Windows x64 版本，尚未提供 macOS 或 Linux 安装包。

目前安装程序未进行代码签名，Windows 可能显示安全提醒。请核对下载地址确实属于本仓库；如不愿运行未签名程序，可以按下文从源码构建。

## 可以做什么

- **按项目阅读**：为不同的阅读、研究或写作任务建立项目，导入并管理 PDF 文献。
- **保留出处**：选择 PDF 文字创建卡片，保存原始选区文字、可编辑的卡片文字、页码和定位信息；卡片可返回原文。
- **随手标注**：在阅读台添加高亮、下划线、灵感和质疑。标注保存在应用中，不改写 PDF 原件。
- **回顾与整理**：卡片库按文献汇总卡片；二次整理支持自定义分类、拖动、剔除与恢复。剔除不等于删除。
- **组织写作材料**：自己创建多级提纲，将同一张卡片关联到不同章节，并把写作材料复制为 Markdown 文本。
- **本地备份**：手动或定时备份数据库，设置备份位置与保留数量，并通过合并导入已有备份。

## 第一次使用

1. 新建项目，并在阅读台导入一份 PDF。书目信息可以导入时填写，也可以稍后补充。
2. 选中原文，创建卡片或添加高亮、下划线；在侧栏记录灵感和质疑。
3. 在卡片库查看摘录，在二次整理中按自己的主题或用途分类。
4. 在写作提纲中创建章节并关联卡片，需要写作材料时使用“复制写作材料”。

首次启动是空资料库，不会自动加入示例内容。

## 本地数据与迁移

项目、卡片、批注和提纲保存在本地 SQLite 数据库中。导入 PDF 时，应用会在自己的数据目录保存一份副本，原文件不会被修改。

数据库备份和项目备份保存研究记录；PDF 文件需要另外保管。迁移到另一台电脑后，可以为缺失的文献重新关联 PDF。备份导入会合并记录，而不是覆盖现有资料；相同记录发生冲突时，保留当前版本。阅读位置、缩放和部分界面展开状态属于本机偏好，不随数据库备份迁移。

关闭主窗口时可以选择隐藏到系统托盘或直接退出。隐藏到托盘时程序仍在运行；完全退出后不会在后台自动备份。

## 当前限制

砚台仍在早期开发阶段。目前不支持扫描件 OCR、跨文献 PDF 全文索引、跨页精确摘录、Markdown/Word 文件直接导出，也没有云同步。提纲的 Markdown 功能是**复制文本到剪贴板**，不是生成文件。遇到无法选择文字的扫描版 PDF，需要先在其他工具中完成 OCR。

更多操作说明见[产品与使用指南](docs/PRODUCT.md)，后续方向见[路线图](docs/ROADMAP.md)。发现问题或希望讨论功能，可以使用本仓库的 Issues。

## 从源码构建

开发环境需要：

- Windows 10/11；
- Node.js 22 或更高版本；
- pnpm；
- Rust stable、rustup；
- Visual Studio 2022 Build Tools（包含 C++ x64 工具）。

```powershell
pnpm install
pnpm setup:rust
pnpm dev
```

如果本机已经配置好项目所需的 Rust 工具链，可以跳过 `pnpm setup:rust`。

构建 Windows 安装包：

```powershell
pnpm build
```

安装包位于 `src-tauri/target/release/bundle/nsis/`。开发检查可运行 `pnpm typecheck`、`pnpm test`、`pnpm test:rust`、`pnpm lint:rust`。

技术细节见[架构说明](docs/ARCHITECTURE.md)和[数据模型](docs/DATA_MODEL.md)。
