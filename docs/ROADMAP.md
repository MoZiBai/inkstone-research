# 分阶段实施计划

## 阶段 0：产品与架构基线

- 固化产品范围、删除语义和四个主视图。
- 建立数据库模型、迁移策略和 IPC 边界。
- 建立工程、代码质量和测试命令。

完成条件：本目录中的产品、数据模型和架构文档与代码结构一致。

## 第一阶段：本地持久化研究工作台

### 实现内容

- 创建和切换项目。
- 新增项目文献记录，查看项目文献。
- 使用明确标识的种子摘录验证卡片库。
- 卡片库按文献分组，显示评论、页码、标签和整理状态。
- 自定义二次整理分类：新增、改名、颜色、排序，以及安全删除非默认分类。
- 卡片分类移动、剔除、定位和恢复。
- 用户创建、编辑、删除和组织多级提纲。
- 卡片关联多个章节、调整章节内顺序、移除关联。
- SQLite 持久化与应用重启恢复。

### 第一阶段验收标准

1. 创建两个项目并在两者之间切换，内容互不串联。
2. 给项目新增文献记录；重启后仍存在。
3. 示例摘录生成的卡片在卡片库中按文献正确分组。
4. 新增、改名、换色和调整分类顺序后，重启状态不变。
5. 卡片拖入其他分类后，卡片库状态同步更新。
6. 剔除卡片后整理板不再显示，但卡片库仍存在并标记为已剔除。
7. 从“已剔除”恢复后回到原分类。
8. 创建三级提纲，调整同级顺序和层级；重启后结构不变。
9. 同一卡片可关联两个章节；从其中一个移除不影响另一个。
10. 永久删除必须二次确认，并只删除项目卡片及其关系。
11. 所有上述状态变化均由 SQLite 持久化，不依赖浏览器 localStorage。
12. 自动化测试覆盖剔除/恢复、分类删除、提纲关联和永久删除不变量。

### 第一阶段之后仍未具备

- OCR、全文索引、文本清理。
- NoteExpress 或其他文献管理器导入。
- Markdown/Word 导出和完整备份恢复。

## 第二阶段：PDF 阅读与可追溯摘录（进行中）

### 已实现

- 接入 PDF.js，连续滚动、页码跳转、缩放和适合宽度；
- 选择本地 PDF，计算 SHA-256，并在应用目录复用只读副本；
- 文字型 PDF 的同页文字选择，创建 `SourceExcerpt` 和 `ProjectCard`；
- 保存 PDF 页码、印刷页、归一化坐标、前后文和文件哈希；
- 卡片跳回原页和选区附近；
- 保存、恢复和移除项目内高亮/下划线 `PdfAnnotation`。

### 阶段验收（当前）

1. 导入 PDF 后可以连续阅读并使用页码/缩放控制。
2. 同页选择文字可以创建带评论、作用和标签的卡片。
3. 选择文字后保存高亮或下划线，重启应用后仍显示。
4. 从卡片库或阅读台侧栏点击卡片/批注可以回到对应页面。

### 尚未实现

- 跨页选区、扫描件 OCR、全文索引和精确/模糊反向定位；
- PDF 复制格式清理和原始/清理版本差异审计。

## 第三阶段：文本质量与扫描件

- 确定性文本清理及变更记录。
- PDF 全文索引、精确/模糊反向定位。
- 本地 OCR 与待核验状态。
- 中英文混排、脚注、双栏和跨页场景测试集。

## 第四阶段：可迁移与写作输出

- JSON/Markdown 备份与恢复。
- Markdown、Word 写作材料和章节证据包导出。
- 数据迁移和审计日志。
- 在核心功能稳定后再评估外部文献管理器集成。
