# 砚台公开路线图

这份路线图用于说明砚台接下来会优先改善什么。具体版本和时间会根据实际使用反馈调整。

## 已完成

- 项目、文献和卡片的本地持久化；
- 按文献浏览卡片库；
- 自定义二次整理分类、拖拽移动、剔除与恢复；
- 用户自建的多级论文提纲和卡片关联；
- PDF.js 阅读、页码跳转、缩放和文字选择；
- 高亮、下划线、灵感和质疑记录；
- 卡片跳回原文位置；
- 完整数据库备份、项目备份和非破坏性合并恢复；
- 自动备份周期、备份目录和保留策略；
- Windows 托盘运行与关闭行为。

## 近期计划

### 阅读体验

- 继续优化跨页选择、选区稳定性和批注操作；
- 改善扫描件打开后的提示和重新链接流程；
- 完善当前页卡片与批注的筛选和定位反馈。

### 文本与检索

- 确定性复制格式清理，同时保留原始文字和修改记录；
- 本地 PDF 全文索引；
- 支持精确定位和可解释的模糊检索结果；
- 为扫描件接入本地 OCR，并标记待核验内容。

### 数据迁移与输出

- JSON/Markdown 结构化备份；
- Markdown、Word 写作材料和章节证据包导出；
- 更清晰的备份校验、恢复和迁移提示；
- 在核心流程稳定后评估外部文献管理器集成。

## 暂不列入核心范围

- 云同步和多人协作；
- 自动生成文章或观点；
- 依赖生成式 AI 的核心工作流；
- WPS 剪贴板兼容入口；
- 自由画布；
- NoteExpress 内部数据库读取或强绑定集成。

路线图之外的建议欢迎通过 Issue 讨论；涉及数据安全、原文可追溯性和本地优先原则的改动会优先评估。
