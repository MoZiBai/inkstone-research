# 砚台（Inkstone）产品与使用指南

## 产品简介

砚台是一款面向深度阅读、资料摘录与想法整理的 Windows 本地卡片工具。它把 PDF 中可追溯的原文片段、阅读时的批注和个人思考放在同一条工作流中，帮助你从“读到一段话”走到“形成一个可使用的观点或写作材料”。

砚台不替用户生成文章，也不要求用户采用固定的研究方法。项目、分类、标签和提纲都可以按照自己的习惯创建和调整。

## 界面概览

每个项目包含四个主要界面：

1. **阅读台**：导入并阅读 PDF，进行选择、摘录、高亮、下划线和阅读记录。
2. **卡片库**：按来源文献浏览当前项目的全部卡片，查看摘录、评论、标签和整理状态。
3. **二次整理**：用自定义分类整理卡片，也可以暂时剔除或恢复卡片。
4. **写作提纲**：创建自己的多级写作提纲，把卡片关联到一个或多个章节。

## 推荐工作流

```text
创建项目 → 导入 PDF → 阅读并标注 → 创建卡片
→ 补充个人理解 → 按主题整理 → 关联写作提纲
```

每个阶段都可以单独进行，不需要在第一次阅读时就决定最终分类或章节归属。

首次打开从空资料库开始。导入 PDF 只需选择文件，书目信息可稍后补充。顶部项目搜索覆盖文献、卡片、灵感、质疑和 PDF 批注；选择结果可以返回相应记录。

## 阅读台

阅读台使用 PDF.js 显示本地 PDF，支持连续阅读、页码跳转、缩放、适合宽度和文字层选择。选择文字后可以：

- 创建阅读卡片；
- 保存高亮；
- 保存下划线；
- 添加与原文位置关联的灵感或质疑。

卡片会保存原始选区文字、可编辑的显示文字、PDF 页码、印刷页码、页面坐标、前后文和文件稳定标识。修改卡片显示文字不会改动原始摘录或 PDF。

高亮和下划线是独立于卡片的项目批注，不会写回 PDF 原文件。应用重启后，批注和定位信息仍会从本地数据库恢复。

阅读侧栏可展开完整卡片、编辑笔记或返回原文。“当前页”模式会分别显示当前页和全篇数量。阅读中的卡片和思考编辑窗口位于右侧，不模糊原文。

灵感和质疑用于随手记录；关联原文片段的笔记可转为卡片，转换成功后原笔记移除。未关联片段的整篇思考目前保留在阅读思考中，可搜索和编辑，尚不能进入二次整理或写作提纲。

## 卡片库

卡片库是当前项目的长期卡片总库，按来源文献分组展示。每张卡片可以查看：

- 原文摘录和个人记录；
- 来源文献、PDF 页码和印刷页码；
- 标签和卡片用途；
- 当前二次整理状态；
- 所关联的提纲章节。

点击“查看原文”可以回到阅读台的对应页面；点击整理状态可以进入二次整理并定位卡片。

## 二次整理

二次整理默认包含当前项目的全部卡片。你可以创建、重命名、着色、排序和删除自定义分类，并在分类之间拖动卡片。

“剔除”不是删除：

- 卡片会从当前整理板隐藏；
- 卡片仍保留在卡片库和来源文献下；
- 原有章节关联不受影响；
- 随时可以从“已剔除”视图恢复。

## 写作提纲

提纲完全由用户创建。你可以建立章、节、小节等层级，为每个节点填写写作说明、核心论点和待解决问题，并调整节点顺序和层级。

把卡片加入章节只是建立关联，不会复制或移动原始卡片。同一张卡片可以被多个章节使用；从某个章节移除时，只会解除这一条章节关联。

“复制写作材料”将全部章节、核心论点、写作说明、问题、关联卡片及来源复制为 Markdown 文本，不受当前折叠和筛选影响。若系统不允许直接写入剪贴板，会显示可手动复制的文本。

## 数据、备份与文件

- 项目数据保存在本地 SQLite 数据库中；
- 导入的 PDF 按 SHA-256 管理只读副本，重复文件会复用；
- 完整数据库备份和项目备份只包含结构化研究数据，不打包 PDF 原件；
- 导入备份后，如果 PDF 所在位置发生变化，可以重新链接文件，卡片、批注和提纲关系会保留；
- 导入采用合并：补入缺少的记录，不重复相同记录，冲突时保留当前版本；这不等于将笔记回退到备份时的版本；
- 自动备份可以设置周期、位置和保留策略，也可以随时手动创建备份。

## 当前支持范围

当前版本已经覆盖项目管理、PDF 阅读、文字摘录、卡片库、二次整理、写作提纲、批注、本地备份合并导入和 Markdown 写作材料复制。扫描件 OCR、跨文献全文索引、跨页摘录、确定性复制格式清理、外部文献管理器导入及 Word/Markdown 文件导出属于后续路线图。
