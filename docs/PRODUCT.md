# 砚台（Inkstone Research Desk）产品说明

## 1. 产品定位

砚台是一款面向深度阅读、资料摘录与想法整理的 Windows 本地卡片工具。它服务于所有希望在阅读中持续记录和组织思考的用户，把从 PDF 中摘录的可追溯材料与阅读时产生的批注、灵感和质疑，经过项目内整理，连接到用户自己建立的多级写作提纲。

核心价值不是替用户管理完整书目，也不是替用户生成文章，而是让每条阅读材料始终能够回答：来自哪篇文献、哪一页、原文是什么、用户当时如何理解，以及它被用于哪些主题或章节。

## 2. 已确认范围

- 本地管理多个同级研究项目。
- 在项目中管理文献记录，并关联应用目录中的本地 PDF 副本。
- 通过内置 PDF 阅读台阅读文字型 PDF、选择文字创建卡片，并保存高亮/下划线批注。
- 以文献为单位查看项目的全部卡片。
- 对全部项目卡片进行二次分类、剔除和恢复。
- 由用户创建多级论文提纲，并把卡片关联到一个或多个章节。
- 使用 SQLite 持久化数据；应用重启后完整恢复。
- 提供后续 JSON/Markdown 备份与导出能力。

当前 PDF 阅读能力以 PDF.js 为基础：PDF 原件只读，导入时计算 SHA-256 并复用相同文件；批注和摘录的页面坐标使用归一化页面坐标保存。扫描件可以导入和翻页，但在 OCR 接入前没有可选择的文字层。

## 3. 当前明确不做

- WPS 剪贴板监听、快捷键捕获或兼容入口。
- 自由画布。
- NoteExpress 导入、同步或内部数据库读取。
- 在线书目检索、查重合并、引用格式管理和 Word 动态引文插件。
- 云同步、多人协作。
- 自动生成论文、自动生成观点或依赖生成式 AI 的核心流程。

## 4. 核心信息架构

每个项目包含四个一级界面：

1. **阅读台**：文献列表、PDF 阅读、摘录与卡片创建。
2. **卡片库**：当前项目全部卡片的永久总库，按来源文献分组。
3. **二次整理**：全部卡片的分类工作区，支持剔除和恢复。
4. **论文提纲**：用户自建的章节树，以及章节与卡片的关联。

项目均为同级容器，不预设“论文 A”“博士论文”等业务类型。

## 5. 核心工作流

### 5.1 阅读与摘录

```text
选择项目 → 打开项目文献 → 阅读 PDF → 选中文字
→ 核对原始文字与清理文字 → 填写即时评论/标签 → 保存卡片
```

保存时记录原始文字、清理文字、PDF 页码、印刷页码、页面坐标、上下文、文件稳定标识及创建时间。原始文字不可被静默改写。

在同一页选中文字后，阅读台提供三种操作：创建研究卡片、保存高亮、保存下划线。高亮和下划线是项目内的可删除批注，不会写回原始 PDF；它们与卡片相互独立，应用重启后从 SQLite 恢复。

### 5.2 卡片回顾

卡片库按文献分组，只展示书目信息、摘录、研究者评论、页码、标签和整理状态。PDF 正文仅在阅读台显示。

点击“查看原文”返回阅读台并定位原页；点击整理状态进入二次整理并定位卡片。

### 5.3 二次整理

项目卡片创建后默认进入初始名为“待归类”的默认分类。用户可以创建、改名、着色和排序分类，并在分类之间移动卡片。删除非默认分类时，卡片会安全移回当前默认分类。

“剔除”仅改变卡片的二次整理状态：

- 不删除卡片；
- 不移除来源文献；
- 不删除提纲关联；
- 可以从“已剔除”视图恢复，恢复后回到剔除前分类。

### 5.4 论文提纲

用户创建章、节、小节，调整层级和顺序，为节点记录写作说明、核心论点与待解决问题。

卡片进入章节时只创建关联。同一卡片可关联多个章节；移除关联不改变卡片库或二次整理状态。

## 6. 删除语义

| 操作 | 改变内容 | 不改变内容 |
|---|---|---|
| 从分类移动 | 当前整理分类 | 卡片、来源、提纲关联 |
| 从二次整理剔除 | 整理状态 | 卡片、来源、提纲关联 |
| 从提纲移除 | 章节—卡片关联 | 卡片、整理状态、其他章节关联 |
| 永久删除卡片 | 项目卡片及其章节关联 | 原 PDF、其他项目卡片 |

永久删除只能在卡片详情或来源文献卡片列表执行，必须二次确认。

## 7. 视觉与交互原则

- 延续旧 Demo 的深墨色、纸张色、陶土色和克制阴影。
- 信息层级与长时间阅读舒适度优先于装饰。
- 左侧项目导航保持稳定；项目内四个视图使用一致的顶部导航。
- 危险操作不用模糊图标表达，明确写出后果。
- 状态变化即时反馈；数据库写入失败时恢复界面状态并说明原因。
- 不用动画掩盖等待；常用操作应在 100 ms 内出现视觉反馈。

## 8. 当前真实能力边界

第一阶段的项目、文献、卡片、整理和提纲操作全部写入真实 SQLite。第二阶段已经接入真实 PDF 导入、PDF.js 渲染、同页文字选择、卡片定位和可持久化高亮/下划线。当前仍不声称具备 OCR、全文索引、跨页摘录、确定性复制格式清理或外部文献管理器导入能力。
