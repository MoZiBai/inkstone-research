# 砚台基础能力补全报告

日期：2026-08-31  
开发基线：`980e43b fix: merge database imports without replacing projects`

## 目标边界

本轮在现有本地应用中完善卡片记录、研究作用、内容编辑、备份安全和大量资料下的基础效率。继续遵守以下不变量：

- 卡片库是当前项目全部卡片的永久总库。
- 从二次整理剔除不是删除。
- 卡片进入提纲只建立关联，从章节移除只解除关联。
- 原始 PDF、不可变选区文字和定位信息不会因修改卡片显示文字而改变。
- 数据库导入采用非破坏性合并，不替换现有项目。
- 本轮不加入生成式 AI、自动写作、云同步、自由画布、NoteExpress 或 WPS 剪贴板功能。

## 阶段一：轻量卡片记录与多研究作用

状态：已实现，提交 `c1b23a4 feat: make card research roles flexible`。

### 数据模型

- 数据库版本由 6 升级到 7。
- 新增 `research_roles`，研究作用归属于项目，保存名称、颜色、顺序、默认项和归档状态。
- 新增 `project_card_roles`，通过关联表支持一张卡片拥有多个研究作用。
- `project_cards` 新增 `origin_kind`，区分普通摘录、由灵感转换和由质疑转换。
- 旧卡片的 `unset` 迁移为没有研究作用；`support / oppose / qualify / background` 迁移到对应的默认研究作用关联。
- 旧 `role` 列暂时仅作为兼容字段保留，不再作为卡片研究作用的业务数据来源。

### 用户流程变化

- 创建卡片时不再要求立即选择“支持、反对、限定、背景”。
- 创建窗口默认突出摘录文字、标签和即时笔记；页码、印刷页码、原始选区和前后文收入“来源与更多信息”。
- 标签输入继续允许自由创建，并通过已有项目标签提供候选。
- 卡片详情可修改显示摘录、印刷页码、即时笔记、标签和多个研究作用。
- 卡片详情可查看原始选区文字、上下文、来源文献、PDF 页码和来源类型。
- 二次整理新增研究作用管理，可创建、重命名、改色、排序、归档和重新启用。
- 归档研究作用不会移除已有卡片关联；已选中的归档作用仍会在卡片详情中显示。

### 转换与数据安全

- 灵感或质疑转为卡片时，来源类型在删除阅读笔记前写入卡片。
- 创建卡片、自动高亮和删除原阅读笔记仍处于同一数据库事务。
- 如果相同原文已经存在项目卡片，转换不会删除原阅读笔记。
- 整体数据库和单项目合并导入同步复制研究作用及其卡片关联，并继续使用 ID 与业务唯一键解析重复对象。

## 阶段三：备份管理与数据库导入预览

状态：已实现，等待阶段提交。

### 数据模型与迁移

- 数据库版本由 7 升级到 8，新增 `backup_records`，登记自动安全备份、完整数据库导出和单项目数据库导出的路径、类型、项目、大小、受管理目录及创建时间。
- 自动备份目录、保留天数及最近清理结果保存在 `app_metadata`，应用重启后继续生效。
- 单项目导出会移除本机备份记录和备份目录设置，避免把与项目无关的本机路径带入项目文件。
- 数据库合并不导入另一台设备的备份目录与清理设置；备份管理设置始终属于当前应用安装环境。

### 备份管理

- “备份与恢复”中可以查看应用登记的备份时间、类型、大小、文件路径、文件可用性和当前总占用空间。
- 可以打开当前自动备份目录、选择并验证自定义目录、恢复默认目录，以及定位单个仍存在的备份文件。
- 更换目录不会移动或删除旧目录中的备份；自定义目录失效时会明确提示并回退默认目录。
- 默认从不自动清理；可选择 7、30、90、180 天或 1–3650 天的自定义保留期。
- 自动清理只逐个处理砚台登记、命名合法且位于当前受管理目录中的自动安全备份；始终保留最近 3 份有效自动备份。
- 手动导出的完整数据库和单项目数据库不参与自动清理。手动删除也只对自动安全备份开放，并显示文件名、时间和大小后二次确认。
- 清理结果记录删除数量、释放空间、失败数量和最近执行时间；单个文件失败不会中止其他文件的处理。
- 界面明确说明数据库备份不复制 PDF 原件，只保存研究数据、文献元数据和 PDF 路径。

### 非破坏性导入预览

- 选择完整数据库或单项目数据库后，先在只读预览流程中验证完整性、迁移临时副本并统计内容，不会立刻修改当前资料库。
- 预览显示项目、文献、卡片、PDF 批注和提纲节点数量，以及预计新增记录、合并已有项目、跳过相同记录、内容冲突和缺失 PDF 数量。
- “冲突”表示稳定标识相同但内容不同；当前资料库版本会被保留，不会被来源文件静默覆盖。
- 确认导入后必须先成功创建自动安全备份，再执行合并；随后显示与预览相同口径的详细结果、备份路径、目录回退警告及自动清理结果。
- 重复导入继续保持幂等；项目、文献、卡片、批注、分类、研究作用和提纲关联不会因重复导入膨胀。
