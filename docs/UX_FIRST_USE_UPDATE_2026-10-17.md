# 首次使用体验优化记录 · 2026-10-17

本轮根据首次使用审查调整已有工作流，不重做信息架构，不增加强制引导或额外确认步骤。

## 已调整

- 新资料库从空项目列表开始；示例数据只用于自动化测试。不会删除已有资料库中的示例或用户记录。
- 项目搜索补齐阅读灵感、质疑、批注文字和评论，按类型展示数量，点击打开相应阅读记录并请求原文定位。
- 阅读侧栏卡片支持展开完整内容、编辑、查看原文。卡片和批注数量区分本页与全篇。
- 阅读中的制卡、卡片编辑和思考编辑使用右侧窗口，不模糊 PDF；保留已有保存、取消和未保存提示，不增加确认层级。
- PDF 导入默认显示文件及标题，作者、年份、引用识别等可选信息折叠；完整书目信息编辑仍可使用全部字段。
- 修正卡片库过时的“尚未接入 PDF”提示；区分项目没有卡片和筛选无结果。卡片库、提纲卡片池提供清除筛选。
- 已有标签显示为可移除的标签块，输入框只显示当前输入；回车或常用分隔符添加，保存时也保留尚未按回车的文字。保留中文输入法的确认操作。
- 卡片库永久删除收进“更多”，右键仍保留；不重复显示“未设置用途”。二次整理的下拉移动和剔除收进“移动 / 剔除”，拖动把手不变。
- 备份入口统一为“备份与导入”，保留周期、目录、数量/时间保留策略、立即备份、导入与导出。明确合并不会回退现有修改；长文件路径默认折叠。
- 提纲增加“复制写作材料”：完整章节层级、核心论点、说明、问题、关联卡片笔记、摘录、来源和章节使用说明，以 Markdown 文本复制。忽略界面筛选与折叠，不改动卡片。剪贴板不可用时提供手动复制文本。
- 更新面向用户的 README 和使用指南。

## 保持不变

- 卡片库、二次整理、提纲使用同一张项目卡片；剔除和章节移除不是永久删除。
- 原始 PDF、摘录坐标、批注定位算法、备份合并策略、自动备份计时不变。
- 文献级独立灵感/质疑仍保留在阅读思考中，尚不能转为无原文卡片；这一产品能力仍待确认。
- 不新增覆盖式恢复、云端功能、生成式 AI、复杂 Word 导出或外部文献管理器集成。

## 验证

- 前端 67 项测试通过，包括新增搜索、筛选空态、卡片侧栏、标签显示、书目折叠、备份入口和提纲材料复制测试。
- Rust/SQLite 48 项测试通过，新增首次启动空库与重启保留项目测试；原有项目导入、合并、共享来源、卡片关联测试保持通过。
- 类型检查、Clippy 和 Windows release 构建通过。
- 未启动用户真实资料库，没有进行真实桌面点击、PDF 选择或系统剪贴板实测；组件渲染测试不等同于桌面视觉验收。
- 构建仍有 PDF 阅读器分块体积提示，不属于本轮新增故障；未据此声称真实大 PDF 阅读帧率已验收。
